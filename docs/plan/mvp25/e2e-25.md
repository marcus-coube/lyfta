# Roteiro E2E — MVP 2.5

Roteiro do passo 1 da P12.4: uma linha por pedido do cliente (tabela "Origem →
tarefa" do [README](README.md)). Coach no Chrome (build web release), aluno no
emulador Android com a rede cortada no treino. Mesma regra do
[e2e-2.md](../mvp2/e2e-2.md): `✅` executado de verdade, `⚠️` exercitado em
parte, `⬜` não executado; o motivo vai nas observações.

## Pré-requisitos

| Item | Como |
|---|---|
| Serviços | identity, workout, assessment, comms (`go run ./cmd/api` com `.env`); billing opcional |
| Redis + MinIO | `cd backend && docker compose up -d` |
| Migrations | workout `0022`, comms `0008` |
| Emulador | `--dart-define` com `10.0.2.2` para os serviços **e** `adb reverse tcp:9000 tcp:9000` (MinIO: a URL presignada é `localhost:9000` e a assinatura inclui o host) |
| Rede cortada | `adb shell svc wifi disable; adb shell svc data disable` (religar com `enable`) |
| Termos | `TERMS_VERSION` `2026-11-v3`: todo usuário reaceita no 1º login |
| Mídia na galeria | `adb push <arquivo> /sdcard/Pictures/` + broadcast `MEDIA_SCANNER_SCAN_FILE` |

## Roteiro (execução de 2026-11-15/16, pilha local, aluno `duo_pixel`, coach Chrome 1280 px e 375 px)

| # | Origem | Passo | Esperado | Resultado |
